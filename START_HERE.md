## 🚀 GET STARTED IN 3 STEPS

### Step 1: Get Your Credentials (5 minutes)

**NeonDB Connection String:**
- Go to: https://console.neon.tech
- Create/select project
- Copy connection string
- Keep it safe

**Gemini API Key:**
- Go to: https://aistudio.google.com
- Click "Get API Key"
- Copy your key
- Keep it safe

### Step 2: Run Setup Script (2 minutes)

**Windows:**
```bash
setup.bat
```

**Mac/Linux:**
```bash
bash setup.sh
```

Or do it manually:
```bash
cd server
cp .env.example .env
# Edit .env with your credentials
npm install

cd ../client
npm install
```

### Step 3: Start the App (2 minutes)

**Terminal 1 - Backend:**
```bash
cd server
npm run dev
```

**Terminal 2 - Frontend:**
```bash
cd client
npm start
```

**Access at:** http://localhost:3000

## 🐛 Common Issues (Quick Fixes)

| Issue | Fix |
|-------|-----|
| Port 5000 in use | Change PORT in .env |
| Module not found | Run `npm install` |
| Database connection failed | Check DATABASE_URL |
| API key not working | Verify GEMINI_API_KEY in .env |
| Frontend won't load | Check backend is running |
| Can't connect to API | Verify proxy in package.json |
